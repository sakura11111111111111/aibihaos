# 修复"选择模式"弹窗样式丢失问题

经过对 CSS 模块化重构的检查，我发现了问题的根源：

**SweetAlert2 弹窗内的自定义 HTML 样式被遗漏了。**

在 `src/views/editor.js` 中，我们使用 SweetAlert2 弹出了两个复杂的窗口：
1.  **归档类别**：使用了 `.category-modal-header`, `.category-tree`, `.tree-item` 等样式。
2.  **复习模式**：使用了 `.review-modal-header`, `.review-mode-list`, `.review-mode-item` 等样式。

**问题在于**：
虽然我们在 `src/styles/views/all-notes.css` 中定义了分类树的样式，但这些样式只对“所有笔记”页面生效。
而在编辑器页面的弹窗中，由于我们将 CSS 拆分得比较细，`editor.css` 中并没有包含这些弹窗所需的样式，导致弹窗内容（分类树、模式列表）失去了样式支持，变得丑陋或不可用。

## 修复计划

1.  **创建 `src/styles/modal.css`**:
    *   将所有与 SweetAlert2 弹窗内容相关的自定义样式（分类树、复习模式列表、弹窗头部等）抽取到一个独立的 CSS 文件中。
    *   这样做的好处是，无论是在编辑器页面还是其他页面，只要有弹窗，都可以复用这套样式。

2.  **更新 `src/main.js`**:
    *   引入这个新的 `modal.css` 文件。

通过这个修复，归档和复习模式选择的弹窗将恢复正常的样式。
