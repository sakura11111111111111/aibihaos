# 待办事项页面增加日历视图

为了解决您“看不到未来任务”的困惑，并提供更好的复习规划体验，我将按照您的要求，在待办事项页面增加一个**日历视图**。

## 设计方案

1.  **布局调整 (Todo View Layout)**：
    *   **左侧面板**：保持不变，但增加一个“日历容器”。
        *   顶部：原有的标题“今日复习任务”。
        *   **中部（新增）**：嵌入一个扁平化的日历组件（Flatpickr Inline Mode）。
        *   下部：原有的任务列表。
    *   **右侧面板**：保持不变，用于预览和执行复习。

2.  **交互逻辑 (Interaction)**：
    *   **默认状态**：日历默认选中“今天”，下方列表显示“今天的复习任务”。
    *   **点击日历**：
        *   当您点击日历上的某一天（例如明天），下方列表会自动刷新，显示**那一天的复习任务**。
        *   这样您就能看到您刚创建的那篇“明天才开始复习”的笔记了。
    *   **视觉反馈**：日历上可以标记出“哪天有任务”（通过 Flatpickr 的 `onDayCreate` 钩子，给有任务的日期加个小红点）。

## 执行步骤

1.  **修改 HTML (`public/partials/todo.html`)**:
    *   在左侧面板中插入 `<div id="todo-calendar"></div>`。

2.  **修改 CSS (`src/styles/views/todo.css`)**:
    *   为日历容器添加样式，确保它在侧边栏中显示得体（可能需要调整高度分配）。

3.  **修改 JS (`src/views/todo.js`)**:
    *   引入 `flatpickr`。
    *   初始化日历实例，开启 `inline: true` 模式。
    *   实现联动逻辑：`onChange` 事件 -> 重新筛选 `allNotes` -> 重新渲染任务列表。
    *   （进阶）实现 `onDayCreate` 逻辑，在日历上标记出有复习任务的日期。

这个方案既满足了您“查看未来任务”的需求，又增加了一个非常实用的“复习日历”功能，让复习计划一目了然。
