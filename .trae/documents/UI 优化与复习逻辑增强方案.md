# UI 优化与复习逻辑增强方案

## 1. 待办事项页面 UI 优化

*   **日历折叠功能**:
    *   在左侧列表顶部添加一个“折叠/展开日历”的按钮（默认折叠）。
    *   用户点击后，日历容器才显示，节省屏幕空间，符合“按需查看”的习惯。
    *   *实现细节*: 使用 JS 控制 `#todo-calendar-container` 的 `display` 属性，并添加过渡动画。

*   **日历红点修复**:
    *   经过检查，`.event-dot` 的样式本身没问题，但可能被 `flatpickr` 的默认样式覆盖或 `overflow` 属性截断。
    *   *修复方案*: 调整 `.flatpickr-day` 的 `overflow` 为 `visible`，并确保红点的 `z-index` 高于日期文字。

*   **其他 UI 细节**:
    *   优化空状态 (Empty State) 的图标和文案。
    *   给任务列表项增加“所属笔记本”或更清晰的日期提示。

## 2. 复习逻辑增强 (忘记/模糊/记住)

我们将单一的“完成复习”按钮替换为更科学的“三按钮反馈机制”，模仿 Anki/SuperMemo 的算法逻辑：

| 按钮 | 含义 | 逻辑行为 | 下次复习 |
| :--- | :--- | :--- | :--- |
| **🔴 忘记 (Forget)** | 完全没印象 | **重置进度**: 回到第 1 阶段 (Index = 0) | **明天** (立刻重来) |
| **🟡 模糊 (Blur)** | 有点印象但模糊 | **保持进度**: 停留在当前阶段 (Index 不变) | **明天** (强化记忆) |
| **🟢 记住 (Remember)** | 记得很清楚 | **推进进度**: 进入下一阶段 (Index + 1) | **按原计划** (例如 2天后) |

3.  **修改 JS (`src/views/todo.js`)**:
    *   实现日历折叠逻辑。
    *   实现 3 个按钮的点击事件，分别对应上述不同的复习算法。
    *   更新 `saveNotes` 和 `renderTodoList`。

这个方案将显著提升复习的科学性和灵活性，同时也解决了您提到的 UI 交互问题。
